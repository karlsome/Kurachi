Freya System v4

Buttons & Badges

Primary Button (.btn-primary)
- Font: Nunito Sans, 15px, Bold (700)
- Color: White text on Brand Green (#1F9D6B)
- Hover: Darker Green (#178A5C)
- Radius: 8px (--btn-radius)
- Usage: Main actions like "Next", "Save", "Submit"
Secondary Button (.btn-secondary)
- Color: Main Text (#1F2733) on White background
- Border: 1px solid #D6DAE3
- Hover: Light Subtle Gray (#F7F8FB)
- Usage: Cancel, Go Back, Alternative actions
Alert Button (.btn-alert)
- Color: White text on Red (#E5484D)
- Usage: Reset, Delete, Stop actions
Breaktime Button (.btn-break)
- Color: White text with Orange/Yellow Gradient (#FFB75E to #ED8F03)
- Shadow: 0 4px 10px rgba(237, 143, 3, 0.3)
- Usage: Starting break time mode
Status Badges
- .status-tag: Gray inset background, 12px text. Used for Machine status.
- .success-icon-badge: Round green circle used in completion cards.

Cards & Forms

Glass Card (.glass-card)
- Background: White (#FFFFFF)
- Border: 1px solid #E6E8EF
- Radius: 12px (--card-radius)
- Shadow: 0 1px 2px rgba(16, 24, 40, 0.04)
- Headers inside (h3): 15px font, bold, bottom border.

Card Title

This is the content inside a standard glass card.

Tap Field (.tap-field)
- Input designed for touch (often opens a keypad or modal).
- Has a blue chevron arrow on the right side.
- Font: 15px, Bold.
Defect Counter (.tap-counter)
- Used for tallying defects. Tap the whole card to +1, tap the minus button to -1.

Modals & Popups

Worker Selection Modal
- Full screen overlay with a centered card. Contains grid of large touchable buttons for names.
Numeric Keypad Modal
- Used for entering quantities on tablets.
Break Time Overlay
- The full-screen break time overlay with animated bouncing dots.
Info Sidebar
- Slides in from the right edge. Use for extra details.
Photo Preview Modal
- Simple dark overlay with a large image and a close button.
Material Photo Gate Modal
- Hard block modal demanding user to take a photo before proceeding.
Lightweight Toast
- Floating dark bubble at the bottom of the screen. Disappears automatically.
